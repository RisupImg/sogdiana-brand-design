# Происхождение и границы анализа

Аудит 16 ноября 2026: публичный https://sogdiana.online/ и локальный мастер сайта. Изучены компоненты, палитры, шаблоны страниц, типографика, геометрия и порядок слоёв в styles.css, app.js, events.js, lines.js; визуально проверены ключевые страницы и состояния. Это анализ дизайн-системы, не полный функциональный тест каждого перехода и каждой анимации.

Публичный CSS на момент просмотра: releases/v56-16-ad9c2008e7179992/styles.css?v=56.16. Локальный index подключает styles.css?v=56.20. Версии различаются. Публичная тёмная тема вычисляет red=#E4464B, но пользователь явно выбрал бордовый; этот пакет закрепляет #AD2026. Старые служебные надписи и лишние номера не становятся правилом бренда.

Наблюдаемые значения: HEX, гарнитуры, пути Bézier, ширины/прозрачности текстуры, алгоритм маски и цвета событий. Рекомендации адаптации: поля слайдов, кегли презентаций, шкала отступов, структура КП и правила производства. Не путать рекомендации с утверждённым брендбуком.

Визуальные семейства сайта: герой с затемнённым видео и контрастной типографикой; карточки событий с индивидуальными акцентами; фотоархив с фотографиями и крупными годами; новости с фильтрами и цветом события; результаты с раскрывающимися строками; магазин с тремя цветовыми семействами; информационные страницы с нейтральным фоном; партнёрская сетка с оптическим выравниванием логотипов; контакты и правовые ссылки в спокойном футере.

Только необходимые дизайн-данные вынесены из проекта. Пользовательские фото, коммерческие документы, персональные данные, настройки публикации, ключи и файлы шрифтов не включены.
