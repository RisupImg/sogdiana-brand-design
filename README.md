# Sogdiana Brand Design

Готовый переносимый skill: дизайн сайтов, коммерческих предложений, презентаций, мерча и соцсетей в визуальной системе Согдианы.

## Использование
Скопируйте папку репозитория в каталог навыков своего агента под именем `sogdiana-brand-design`. Для Codex — `$CODEX_HOME/skills/sogdiana-brand-design` (обычно `~/.codex/skills/sogdiana-brand-design`). Затем вызовите `$sogdiana-brand-design` и укажите носитель, событие, формат, текст и исходные фото. В другом инструменте передайте SKILL.md вместе с references и assets.

Примеры:
- «Используй $sogdiana-brand-design: КП КультЗабега, 6 слайдов, реальные фото партнёрских зон».
- «Создай макет футболки ночного забега: перед/спина, фирменные волны».
- «Собери лендинг в стиле Согдианы для моего бренда, сохрани мой логотип».

## Содержимое
- SKILL.md — рабочий процесс и обязательные правила.
- references — цвета, шрифты, события, слои фотографии, движение, носители и проверка.
- assets/tokens.json — переносимые значения.
- assets/texture-gray.svg — тонкая серая текстура.
- assets/ribbons — семь цветовых вариантов событий.
- assets/line-geometries.json — исходные пути и толщины.

Аудит и различия публичной/локальной версии описаны в references/audit.md. Репозиторий содержит оригинальные векторные логотипы Согдианы из Figma в assets/logos; источник и правила применения — в assets/logos/README.md. Оригинальные фото и шрифты не включены; права на их использование нужно получать отдельно. Сайт этим пакетом не изменяется и не публикуется.
