# Оригинальные логотипы Согдианы

Экспортированы из Figma 16.11.2026 без перерисовки и изменения геометрии.

- `sogdiana-lockup-burgundy.svg` — бордовый #AD2026 для светлого фона; узел 86:4.
- `sogdiana-lockup-cream.svg` — кремовый #FAF5E8 для тёмного и бордового фона; узел 102:368.

Источник: https://www.figma.com/design/z1pk1SOGXZcLMrh5Wv2IUM/?node-id=102-368

Знак в круге и надпись являются единым оригинальным вектором. Не заменять знак буквами G/CTG, не перерисовывать и не растягивать пропорции. При переносе стиля на чужой бренд использовать его собственный логотип. Публикация файлов не передаёт права на товарный знак.

Для шоурила используйте `sogdiana-wordmark-cream.svg`: только надпись, без круглого знака. Это кадрирование оригинального вектора без изменения контуров. В шапке сайта остаётся полный логотип.
